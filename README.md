# 空間桌布編輯器

在電腦上排版「分層空間桌布」,匯出成 WallEngine App 可以匯入的桌布包(`.zip`)。
純網頁工具,不需要安裝或建置:用瀏覽器開啟 `index.html` 即可(Chrome 或 Edge)。

## 怎麼用

1. **加入圖層**:按「＋ 圖片或影片」,或把檔案拖進視窗。第一個檔案會成為背景;之後加入的會排在更靠近你的位置。
   前景請用透明背景的 PNG/WebP。
2. **擺位置**(右邊的手機預覽):點選圖層後拖曳移動、滾輪縮放、Shift + 滾輪旋轉、方向鍵微調。
3. **排遠近**(中間的 3D 空間):拖曳空白處旋轉視角,直接拖曳某個圖層就能前後移動它。
   深度 0 是最近、1 是最遠;也可以用右側的滑桿或 `[` `]` 鍵。
4. **看效果**:勾選「傾斜預覽」,在手機預覽上移動滑鼠模擬傾斜手機;滑鼠移開後會自動搖擺。
5. **匯出**:按「匯出桌布包 .zip」,把檔案傳到手機,在 App 裡選
   「匯入 → Shader / 插件包 → 插件包(.zip)」。

「儲存專案」會存成 `.wallproj.json`(圖片與影片都內嵌在裡面),之後用「開啟專案」繼續編輯。

## 預覽與手機上的差異

手機預覽用的是和 App 相同的視差公式,位置、大小與傾斜時的位移都一致。要知道的幾點:

- **越近的圖層會被放大一點**。App 為了讓圖層傾斜時不露出邊緣,會把每個圖層放大
  `1 + 2 × 視差強度 × |對焦深度 − 圖層深度|` 倍。預覽已經包含這個放大,所以看到的就是結果,
  但圖層貼近畫布邊緣的內容會被裁掉一些。
- **「對焦深度」的圖層不動**。預設是 1(背景不動,越近動越多)。設成 0.5 的話,遠近兩側會朝相反方向移動。
- **動態效果**(光塵、飄雪、下雨)只在手機上顯示,編輯器沒有預覽。
- **最遠的圖層要填滿畫布**,否則空白處在手機上是黑色(編輯器會提醒)。

## 影片圖層

- 影片不會重新編碼,原檔直接放進桌布包,由 App 依你擺的位置、縮放、旋轉、不透明度播放。
  請使用接近螢幕解析度的影片;4K 影片會白白耗電。
- 影片沒有透明度。要疊加火花、光暈這類**黑底特效影片**,把「混合方式」設為「相加」或「濾色」。
- 影片不能水平翻轉。
- 瀏覽器能播放的格式才能預覽(H.264 的 MP4 最保險)。
- 桌布包上限約 300 MB(App 匯入時的限制)。
- 每多一個影片圖層,手機就多一路解碼,同時播放兩三個以上會明顯耗電。

## 匯出的內容

```
manifest.json     名稱、畫布大小、視差設定、各圖層的檔名與深度
layer0.jpg/.png   圖片圖層:已依位置、縮放、旋轉畫成整張畫布大小(不透明存 JPG,有透明存 PNG)
layer1.mp4        影片圖層:原檔,擺放參數寫在 manifest 裡
effect.frag       有選動態效果時才有
thumb.jpg         App 桌布庫顯示的縮圖
```

格式細節見 App 專案的 `docs/PACK_FORMAT.md`。

## 檔案

- `index.html`、`style.css`:介面
- `js/app.js`:編輯器本體(狀態、手機預覽、3D 視圖、匯出、專案檔)
- `js/zip.js`:不壓縮的 ZIP 寫入器
- `js/effects.js`:動態效果的 shader 原始碼,與 App 內 `assets/effects` 相同;兩邊修改時要同步
