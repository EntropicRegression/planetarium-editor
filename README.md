# 空間桌布編輯器

在電腦上排版「分層空間桌布」,匯出成 Planetarium App 可以匯入的桌布包(`.zip`)。
純網頁工具,不需要安裝或建置。兩種開啟方式:

- **直接開啟** `index.html`(Chrome 或 Edge)。所有編輯功能、Claude、Gemini 和 OpenAI API 金鑰都能用。
- **用本機輔助程式開啟**(需要 Python 3.8+,不需安裝任何套件),才能「用 ChatGPT 登入」:

  ```bash
  python serve.py --open
  ```

  它只監聽本機(127.0.0.1:8765),詳見下方「用 ChatGPT 登入」。

## 怎麼用

1. **加入圖層**:按「＋ 圖片或影片」,或把檔案拖進視窗。第一個檔案會成為背景;之後加入的會排在更靠近你的位置。
   前景請用透明背景的 PNG/WebP。
2. **擺位置**(右邊的手機預覽):點選圖層後拖曳移動、滾輪縮放、Shift + 滾輪旋轉、方向鍵微調。
   只想用圖片的一部分時,拖曳框線中間的白色方塊**裁切**那一側(或用右側的裁切滑桿);裁切不會移動圖片。
3. **排遠近**(中間的 3D 空間):拖曳空白處旋轉視角,Shift 或右鍵拖曳平移,滾輪縮放。選取圖層後會出現三個箭頭,
   拖曳紅、綠、藍箭頭分別沿左右、上下、遠近移動;直接拖曳圖層本身也能前後移動。
   「正面/側面/俯視」按鈕(或 `1`/`3`/`7`)切換視角,`F` 置中。
   深度 0 是最近、1 是最遠;也可以用右側的滑桿或 `[` `]` 鍵。
4. **看效果**:勾選「傾斜預覽」,在手機預覽上移動滑鼠模擬傾斜手機;滑鼠移開後會自動搖擺。
5. **匯出**:按「匯出桌布包 .zip」,把檔案傳到手機,在 App 裡選
   「匯入 → Shader / 插件包 → 插件包(.zip)」。

**專案會自動儲存**在這個瀏覽器裡,下次開啟時自動還原。要備份或換電腦,用「儲存專案」存成
`.wallproj.json`(圖片與影片都內嵌在裡面),之後用「開啟專案」讀回。

「開啟專案」也能直接開**桌布包 `.zip`**(這個編輯器或 App 匯出的都可以),或把檔案拖進視窗:
每個圖片、影片圖層會變成同樣深度的圖層,可以繼續編輯再匯出。桌布包裡的圖層已經畫成整張畫布大小,
所以原本的個別位置、縮放不會還原;自訂 shader、景深圖和動畫貼片編輯器無法顯示,會略過並提示。

其他小功能:

- 第一次開啟時可以按「看看範例」載入一個做好的場景來玩。
- 圖層列表:把圖層拖到另一個圖層上可調整前後順序;按兩下名稱改名;鎖頭圖示鎖定後,在預覽上點不到也拖不動;眼睛圖示切換顯示。
- 「匯出預覽圖」把靜止時的畫面存成一張 PNG,方便分享或當一般桌布用。
- 工具列的「EN / 中文」切換介面語言(繁體中文、英文)。
- 手機預覽右上的選單可以疊上**主畫面**或**鎖定畫面**的介面位置(時鐘、圖示、搜尋列),
  檢查主體有沒有被擋住。這只是參考線,不會匯出。
- 按 `?` 看完整的操作與快捷鍵說明。

## AI 助手

按工具列的「AI 助手」,用文字描述想要的畫面(也可以附參考圖),它會把畫面拆成不同遠近的圖層做出來,
做完自己檢視、傾斜檢查、修正。做出來的就是一般圖層,可以繼續手動調整,每一步都能復原。

### 選擇模型

在助手面板按「設定」。對話模型有四種來源:

| 來源 | 需要 | 備註 |
|---|---|---|
| Claude(Anthropic) | Anthropic API 金鑰 | 預設 Claude Opus 5.5 |
| Gemini(Google) | Gemini API 金鑰 | 預設 Gemini 4 Hydrogen,有免費額度 |
| OpenAI | OpenAI API 金鑰 | 預設 GPT-6.1 Sol |
| ChatGPT | 用 ChatGPT 帳號登入 | 用量算在訂閱方案上;需要 `serve.py` |

填好之後按「**測試連線**」:它會用你選的來源、模型和金鑰送出一個很小的請求,成功會顯示模型的回覆,
失敗會顯示原因(金鑰無效、沒有權限、額度用完、模型名稱不存在…)。第一次使用某個來源時建議先測。

金鑰只存在你的瀏覽器(沒勾「記住」的話關閉頁面就清除),只會傳給它所屬的服務。
換來源或模型會開始新的對話,圖層不受影響。面板下方會顯示本次對話用掉的 token 數。

### 用 ChatGPT 登入

這是 OpenAI 官方提供給本機、開源工具的「Sign in with ChatGPT」流程:用你自己的 ChatGPT 帳號登入,
之後的用量算在你的訂閱方案上,不需要 API 金鑰。

1. 用 `python serve.py --open` 開啟編輯器(不能用直接開啟 `index.html` 的方式)。
2. 助手面板 →「設定」→ 來源選「ChatGPT」→ 按「登入」,在新分頁完成 OpenAI 的登入。
3. 回到編輯器,狀態會變成「已登入」,模型清單會換成你的帳號可用的模型。

需要 `serve.py` 的原因:OpenAI 登入完成後會把結果送回一個本機位址,必須有程式在那裡接收;
它也負責換發和保存權杖,權杖存在你的家目錄 `~/.planetarium-editor/openai.json`,網頁本身拿不到。
`serve.py` 只監聽 127.0.0.1、只轉送到固定的幾個 OpenAI 端點、拒絕不是來自自己頁面的請求。

限制:這個登入方式不能生成圖片;哪些方案符合資格由 OpenAI 決定,不符合時登入會被拒絕並顯示原因。

### 它怎麼做圖層

- **用畫的**:預設情況下圖層是它寫出來的向量圖(SVG)或像素格。擅長插畫、剪影、像素風、漸層光影。
- **生成素材**:在設定的「素材生成」選一個圖片模型後,它還能自己生成繪畫或照片質感的圖
  (天空、風景、角色、材質)當圖層。每張圖另外計費。GPT Image 原生支援去背;
  Gemini 圖片模型會先生成在純色背景上,再由編輯器自動去背。
  評估、做法與限制見 [docs/ASSET_GENERATION.md](docs/ASSET_GENERATION.md)。
- **參考圖**:按「＋ 參考圖」、直接貼上,或拖進助手面板。它會參考構圖、配色和氣氛;
  你也可以要求把照片本身放進圖層。
- **修改現有畫面**:直接說「把山調低一點」「加一隻貓在欄杆上」「前景太暗」。它會先讀目前的圖層再動手,
  不會刪掉你自己匯入的圖層,除非你要求。
- 「停止」會中斷目前的回覆;已經做好的圖層會留著。「新對話」只清除對話,不動圖層。

教它怎麼分層的說明(系統提示)和工具定義在 `js/ai/core.js`,想調整它的做法就改那裡。

## 預覽與手機上的差異

手機預覽用的是和 App 相同的視差公式,位置、大小與傾斜時的位移都一致。要知道的幾點:

- **越近的圖層會被放大一點**。App 為了讓圖層傾斜時不露出邊緣,會把每個圖層放大
  `1 + 2 × 視差強度 × |對焦深度 − 圖層深度|` 倍。預覽已經包含這個放大,所以看到的就是結果,
  但圖層貼近畫布邊緣的內容會被裁掉一些。
- **「對焦深度」的圖層不動**。預設是 1(背景不動,越近動越多)。設成 0.5 的話,遠近兩側會朝相反方向移動。
- **動態效果**(光塵、飄雪、下雨)只在手機上顯示,編輯器沒有預覽。
- **最遠的圖層要填滿畫布**,否則空白處在手機上是黑色(編輯器會提醒)。

## 影片圖層

- 影片不會重新編碼,原檔直接放進桌布包,由 App 依你擺的位置、縮放、旋轉、不透明度播放。
  請使用接近螢幕解析度的影片;4K 影片會白白耗電。
- 影片沒有透明度。要疊加火花、光暈這類**黑底特效影片**,把「混合方式」設為「相加」或「濾色」。
- 影片不能水平翻轉。
- 瀏覽器能播放的格式才能預覽(H.264 的 MP4 最保險)。
- 桌布包上限約 300 MB(App 匯入時的限制)。
- 每多一個影片圖層,手機就多一路解碼,同時播放兩三個以上會明顯耗電。

## 匯出的內容

```
manifest.json     名稱、畫布大小、視差設定、各圖層的檔名與深度
layer0.jpg/.png   圖片圖層:已依位置、縮放、旋轉畫成整張畫布大小(不透明存 JPG,有透明存 PNG)
layer1.mp4        影片圖層:原檔,擺放參數寫在 manifest 裡
effect.frag       有選動態效果時才有
thumb.jpg         App 桌布庫顯示的縮圖
```

格式細節見 App 專案的 `docs/PACK_FORMAT.md`。

## 檔案

- `index.html`、`style.css`:介面
- `js/app.js`:編輯器本體(狀態、手機預覽、3D 視圖、匯出、專案檔、自動儲存),以及給 AI 助手用的操作介面
- `js/assistant.js`:AI 助手的面板、設定與對話迴圈(不分模型來源)
- `js/ai/core.js`:給模型的說明、工具定義、各來源共用的小工具
- `js/ai/claude.js`、`gemini.js`、`openai.js`:三家的接法。要加新的來源,照 `core.js` 開頭的介面再寫一個即可
- `js/vendor/anthropic-sdk.js`:Anthropic 官方 JavaScript SDK 1.8.0 打包成單一檔案(Apache-2.0,授權見同目錄),
  第一次使用 Claude 時才載入。重新產生的方式:`npm install @anthropic-ai/sdk esbuild` 後執行
  `npx esbuild entry.mjs --bundle --format=iife --global-name=AnthropicSDK --platform=browser --minify`,
  其中 `entry.mjs` 內容為 `import Anthropic from "@anthropic-ai/sdk"; export default Anthropic;`
- `serve.py`:本機輔助程式(ChatGPT 登入、轉送 OpenAI 請求),只用 Python 標準函式庫
- `js/zip.js`:不壓縮的 ZIP 寫入器
- `js/effects.js`:動態效果的 shader 原始碼,與 App 內 `assets/effects` 相同;兩邊修改時要同步
- `js/i18n.js`、`js/i18n-en.js`:介面語言與英文翻譯表。新增或修改介面文字後執行 `node tools/i18n-scan.js`,
  它會列出還沒翻譯的字串和已經沒用到的翻譯
- `tests/providers.test.js`:三家模型來源與圖片模型的自動化測試,用罐頭回覆,不需要金鑰:`node tests/providers.test.js`
- `docs/ASSET_GENERATION.md`:素材生成的評估與做法
